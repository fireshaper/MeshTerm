# MeshTerm — Architecture

How the code is laid out as built. Update this file after every phase.

## Packages

pnpm workspace (default isolated linker). Packages depend on each other with `workspace:*`, and each package's `exports` points at `src/index.ts`.

| Package               | Path                 | Responsibility                                                                                                                                           |
| --------------------- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@meshterm/shared`    | `packages/shared`    | Zod schemas and inferred types shared by server and web: runtime config, domain types, WS protocol.                                                      |
| `@meshterm/protocol`  | `packages/protocol`  | Protobuf codec + stream framer. The only package that imports `@meshtastic/protobufs`/`@bufbuild/protobuf`; re-exports them.                             |
| `@meshterm/fake-node` | `packages/fake-node` | Test double: TCP server speaking real Meshtastic framing, scenarios, transmit audit.                                                                     |
| `@meshterm/server`    | `apps/server`        | Fastify server: REST, WebSocket, send endpoint, health; NodeConnection, SQLite, event pipeline (Phases 3–7). Entry `src/main.ts`, bundle `dist/main.js`. |
| `@meshterm/web`       | `apps/web`           | React 19 + Vite SPA: app shell, routes, tokens and base CSS (Phase 8). Live data comes in Phase 9.                                                       |

Root tooling files: `tsconfig.base.json` (strict settings), `tsconfig.json` (root config files), `vitest.config.ts` (projects = `apps/*`, `packages/*`), `eslint.config.js`, `stylelint.config.js`, `.prettierrc.json`.

### `apps/server/src/events`

Flow: `NodeConnection` → `wireConnection` (decoder) → hub `radio.*` events → `attachPersistence` (SQLite) → hub public events (later: WS fan-out).

| File             | Responsibility                                                                                                                                                                                                                                                                                                                                                                                                                |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hub.ts`         | `EventHub<Events>`: `subscribe(type, fn) → unsubscribe`, `subscribeAll(fn)`, `publish(type, payload)`. Synchronous; a throwing subscriber is logged and the others still run.                                                                                                                                                                                                                                                 |
| `events.ts`      | `RadioEvents` (internal: `radio.myInfo`, `radio.node` {`NodeUpdate`}, `radio.channel`, `radio.text`, `radio.routing`, `radio.packet`, `radio.telemetry`, `radio.position`), `PublicEvents` (`connection.state`, `node.upsert`, `message.new`, `message.status`, `telemetry.new`, `position.new` with WS payload shapes, plus `channel.upsert`), `HubEvents`, `Hub`.                                                           |
| `decoder.ts`     | Pure `decodeFromRadio(fromRadio, {connectionId, now, newId}) → {events, ignored}` (my_info, node_info, channel without PSK, TEXT_MESSAGE_APP, NODEINFO_APP, ROUTING_APP, TELEMETRY_APP (device/environment), POSITION_APP, and the position/device metrics inside handshake NodeInfo; everything else is `ignored` with a reason). `nodeHeard(fromRadio, ctx)`: a `radio.node` last-heard/SNR/hops update for **any** packet. |
| `persistence.ts` | `attachPersistence(hub, db, logger, now)`: writes each `radio.*` event (incl. telemetry, positions, RSSI, last packet; `telemetry.new`/`position.new` only for new history) and publishes the public event from what was stored (no `message.new` for duplicates; `acked` is final). `mergeNode` rules: absent fields kept, `lastHeard` never goes back, `snr`/`hopsAway` only from updates at least as recent.               |
| `pipeline.ts`    | `wireConnection(conn, hub, {logger, now, newId})`: state → `connection.state`; each `FromRadio` → `nodeHeard` + decoder events; ignored frames logged at debug.                                                                                                                                                                                                                                                               |
| `recorded.ts`    | `recordFrames()`: captures real frames from a FakeNode session (handshake, channel text, DM, node info, ACK, NAK, telemetry) for decoder tests.                                                                                                                                                                                                                                                                               |

### `apps/server/src/activity`

| File          | Responsibility                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `recorder.ts` | `attachActivity(hub, db, {now, maxRows, maxAgeMs})`: subscribes to public events and records feed entries in `activity`, publishing `activity.new`: `message.in`/`message.out` (preview ≤ 80 chars, channel index in `value` for broadcasts), `node.new` (not in the node DB before) and `node.back` (heard again after more than `staleMin`; `value` = quiet ms) — node events only while `connected` and never for my node; `power.changed` (battery state ok/low/critical/external changed; `detail` = `from→to`); `connection.lost` (from `connected`) / `connection.restored` (`value` = downtime). | `network.ts`  | `attachNetworkStats(hub, db)`: counts every `radio.packet` from another node into `packet_stats` (per minute, node, port; my node's own packets skipped; pruned after 7 days every 500 inserts) and stores `radio.neighbors` reports (each replaces the reporter's list). `buildTopology(db, connectionId, windowMs, now)`: nodes heard within the window plus only observed links — `direct` (my node ↔ a node whose last packet had 0 hops; SNR as my node measured) and `reported` (NeighborInfo within the window, both ends shown). `packetRows(db, connectionId, from, to, bucketMs)`: SQL-side bucket sums (integer literals; a bound JS number is REAL). `buildTraffic` adds `packets`, `packetsByPort`, `ports` (window totals) and `topNodes` (5); `nodeHistory` adds `heard` (packets per 1 h / 6 h).                        |

### `apps/server/src/tiles`

| File            | Responsibility                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `tile-cache.ts` | `TileCache({dir, upstream, maxBytes, ttlMs = 30 d, now, fetchImpl, timeoutMs, maxConcurrent = 2})`: on-disk cache `<dir>/<z>/<x>/<y>.png` for `config.tileUrl`. `get(z, x, y)` → `{body, contentType, source: hit\|miss\|stale}`. The expiry is stored as the file's mtime (`cacheTtl`: upstream `max-age` if shorter, else `Expires`; at most 2 upstream requests at once, the rest queued (OSM tile policy); `no-store`/`no-cache` aren't cached). LRU eviction by last use to stay under `maxBytes` (index rebuilt from disk at startup). Concurrent requests for a tile share one fetch. Upstream failure serves an expired copy if there is one, else `TileError(502)`; out-of-range coordinates `TileError(400)`. Sends a MeshTerm `User-Agent` (OSM tile policy). |

## Database schema

SQLite at `<MESHTERM_DATA_DIR>/meshterm.db` (WAL, `synchronous=NORMAL`, `foreign_keys=ON`, `busy_timeout=5000`). Drizzle schema: `apps/server/src/db/schema.ts`. Migrations: `apps/server/drizzle/` (generated by `db:generate`, applied on every start by `initDatabase`). All timestamps are epoch **milliseconds**. Node numbers and packet ids are uint32 stored as INTEGER. Booleans are INTEGER 0/1.

Migrations: `0000_base_schema`, `0001_message_dedupe`, `0002_connection_my_node_num`, `0003_dashboard_data`, `0004_dashboard_api`.

## WebSocket protocol

Schemas are defined in `packages/shared/src/ws.ts`; the server side is `apps/server/src/ws/`. One `snapshot` per `subscribe`, then live events for that connection only. Outgoing message lifecycle seen by clients: `message.new` (status `queued`) → `message.status` `sent` → `acked` or `failed`.

Client → server:

| `type`      | Fields         |
| ----------- | -------------- |
| `subscribe` | `connectionId` |

Server → client:

| `type`             | Fields                                                                                                                                                                  |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `snapshot`         | `connectionId`, `state`, `myNodeNum` (nullable), `nodes[]`, `channels[]`, `channelMessages[]` (`{ channelIndex, messages[] }`), `dmMessages[]` (`{ peer, messages[] }`) |
| `connection.state` | `connectionId`, `state`, `previous` (nullable), `reason` (nullable)                                                                                                     |
| `node.upsert`      | `node`                                                                                                                                                                  |
| `message.new`      | `message`                                                                                                                                                               |
| `message.status`   | `connectionId`, `messageId`, `status`, `errorReason` (NAK `Routing.Error` name or null)                                                                                 |
| `telemetry.new`    | `telemetry` (`TelemetryReport`: `{connectionId, nodeNum, time, kind: "device", device}` or `{…, kind: "environment", environment}`)                                     |
| `activity.new`     | `activity` (`ActivityEvent`: `id`, `connectionId`, `time`, `kind`, `nodeNum`, `messageId`, `value`, `detail`)                                                           |
| `position.new`     | `position` (`NodePosition`: `connectionId`, `nodeNum`, `lat`, `lon`, `altitude`, `precisionBits`, `time`)                                                               |
| `error`            | `code`, `message`                                                                                                                                                       |
