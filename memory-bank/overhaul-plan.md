# MeshTerm — Dashboard UI/UX Overhaul Plan

Plan for the "Dashboard UI/UX Overhaul" change request (pasted by the user on 2026-10-19). Same rules as the other plans: steps in order, each done when its tests pass and `typecheck`, `lint`, `format:check`, `test`, `test:e2e` stay green; stop after every phase; record choices in `DECISIONS.md`; theming rules from `CLAUDE.md` (tokens only, `data-mt` hooks, no literal colors outside `themes/`, Radix unstyled only); never transmit on the mesh in tests.

## 4. Phases

**O1 — Visual foundation (frontend + B1).** Dark-first token palette in the Default theme, new shell (header, collapsible sidebar, mobile drawer), dashboard header, KPI cards, 12-column responsive grid, node previews grouped on the dashboard, full inventory moved to the Nodes page (cards/table, filters). Tests: component tests for each new component and grouping rules; e2e at 390/768/1280/1440 px with no horizontal scroll; updated visual baselines.

**O2 — Dashboard intelligence (B2, B4, B5, B6).** Traffic chart (messages, util), node details drawer, activity feed, reconnect, toasts, skeletons, tooltips explaining metrics, staleness labels. Tests: endpoint tests with fixtures, feed rules (no trivial spam), drawer keyboard/focus handling, e2e with FakeNode injections.

**O3 — Network visualization (B3, B7).** Packet statistics in the chart, accurate network view, insights. Tests: FakeNode NeighborInfo fixtures; the view never draws an edge that isn't a direct observation or a reported neighbor link.

## 5. Decisions (2026-10-19)

Default theme dark by default; all backend changes, phase by phase; mobile drawer replaces the tab bar; stop after each phase. **O1, O2 and O3 done** (see `progress.md`).
